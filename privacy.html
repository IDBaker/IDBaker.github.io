Privacy Policy – Isaiah Local CLI

Last updated: October 10, 2026

Isaiah Local CLI is a personal tool used only by its owner, and only with the owner's own Google accounts.

  • Data accessed: Gmail and Google Drive content of the owner's own accounts, using read-only access.
  • How it is used: Solely to let the owner search and read their own email and files on their own computer.
  • Storage: Authorization tokens are stored encrypted on the owner's computer. No data is stored on any server operated by this app.
  • Sharing: No data is sold, shared, or transferred to any third party.
  • Revoking access: Access can be revoked at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
